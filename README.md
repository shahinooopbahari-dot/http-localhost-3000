# ShahinLearn — local interactive prototype

## Run on Windows
1. Extract this ZIP.
2. Double-click `run-shahinlearn.bat`.
3. Keep the terminal window open.
4. Open http://localhost:3000 in your browser.

Node.js LTS and an internet connection are required for the first dependency install.

## What is interactive in this build
- Navigation opens working workspace panels.
- Notes can be searched and bookmarked in the UI.
- Upload flow accepts a file selection and title for a local UI demonstration; files are not uploaded to a server.
- Chat and calendar can be tried locally in this browser session.
- Pomodoro timer can start, pause, and reset.
- AI tool links open the corresponding independent services.

## Important limitations
This is still a local, single-browser prototype. It does not yet have a backend, database, user accounts, shared multi-user chat, real file storage, university-system integration, or real-time video calls. Do not enter sensitive personal data. Production use requires secure backend/API configuration, authentication, database, storage, and deployment.

## ورود و ثبت‌نام آزمایشی
- در نسخه محلی، فرم نام، نام خانوادگی و شماره تلفن اضافه شده است.
- برای آزمایش کد یک‌بارمصرف، کد ثابت `123456` را وارد کنید.
- این حالت کاملاً محلی و رایگان است و پیامک واقعی ارسال نمی‌کند؛ مشخصات کاربر فقط در localStorage همان مرورگر ذخیره می‌شود.
- برای ارسال پیامک واقعی باید سرویس پیامکی، بک‌اند، محدودسازی درخواست‌ها و نگهداری امن کدهای یک‌بارمصرف تنظیم شوند. هزینه و سهمیه رایگان به ارائه‌دهنده و کشور بستگی دارد.
